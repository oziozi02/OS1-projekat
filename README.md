## RISC-V Operating System

A multithreaded operating system kernel developed for the RISC-V architecture as part of the Operating Systems 1 course at the University of Belgrade, School of Electrical Engineering.

### Features

- Memory allocation
- Thread creation and scheduling
- Synchronization using semaphores
- Sleep timers and thread management
- Interrupt handling
- Console I/O
- System-call interfaces through C++ and C APIs

### Development and Execution Environment

This project requires the virtual machine provided for the university course, which must be run using VMware. The supplied environment contains the tools required to build and execute the operating system; it is not configured to run directly on a standard host environment.
